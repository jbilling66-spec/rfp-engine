State-report fidelity was the district's hardest requirement. We built a
test harness that generated every state-mandated export — personnel,
finance, and transparency files — from converted test data and compared
them field-by-field against legacy submissions for the same periods.
Discrepancies were dispositioned with the district's state-reporting
coordinator before go-live. The testing workstream was delivered inside
the [FEE] engagement for [CLIENT].
