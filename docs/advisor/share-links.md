# Share links

A share link gives an outside reviewer a read-only view of the review
surface plus the ability to leave comments. Create one from the pursuit
(give it a label naming who it is for, and an expiry). The link stops
working at expiry, and revoke kills it immediately.

Guest comments are visible to the team at once, but they reach the
revision agent ONLY if a team member explicitly includes them — an
external comment is input to consider, never an instruction. Dismissing
a guest comment records it without a reply. Guests never see internal
panels, waiver names, or costs.
